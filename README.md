# Web Studio

Простой проект с Vite сборкой, поддерживающий HTML, SCSS и JavaScript.

## Структура проекта

```
web-studio/
├── index.html              # Главный HTML файл
├── src/
│   ├── main.js            # Точка входа JavaScript
│   ├── js/                # JavaScript модули
│   │   ├── app.js        # Основная логика приложения
│   │   ├── components.js # UI компоненты
│   │   └── utils.js      # Утилитарные функции
│   └── styles/            # SCSS модули
│       ├── main.scss     # Главный файл стилей
│       ├── _variables.scss # Переменные SCSS
│       ├── _base.scss    # Базовые стили и сброс
│       ├── _layout.scss  # Стили layout
│       ├── _typography.scss # Типографика
│       └── _components.scss # Стили компонентов
├── vite.config.mjs        # Конфигурация Vite
└── package.json           # Зависимости и скрипты
```

## Установка зависимостей

```bash
npm install
```

## Доступные команды

### Режим разработки
Запускает локальный сервер с горячей перезагрузкой:
```bash
npm run dev
```
Сервер будет доступен по адресу: http://localhost:3000

### Сборка для продакшена
Собирает проект в папку `dist`:
```bash
npm run build
```

### Предпросмотр сборки
Запускает локальный сервер для предпросмотра собранного проекта:
```bash
npm run preview
```

## Особенности

- **Vite** - Быстрый сборщик с горячей перезагрузкой
- **Модульный JavaScript** - ES Modules для организации кода
- **Модульный SCSS** - Современный @use синтаксис для организации стилей
- **Автоматическая компиляция** - SCSS компилируется на лету
- **Чистая архитектура** - Разделение на утилиты, компоненты и основную логику

## Разработка

### JavaScript модули
- `src/js/utils.js` - Утилитарные функции (createElement, logMessage)
- `src/js/components.js` - Переиспользуемые UI компоненты
- `src/js/app.js` - Основная логика приложения
- `src/main.js` - Точка входа, импортирует все модули

### SCSS модули
- `src/styles/_variables.scss` - Все переменные (цвета, отступы, шрифты)
- `src/styles/_base.scss` - Базовые стили и сброс
- `src/styles/_layout.scss` - Стили layout компонентов
- `src/styles/_typography.scss` - Типографика
- `src/styles/_components.scss` - Стили UI компонентов
- `src/styles/main.scss` - Главный файл, импортирует все модули

### Рабочий процесс
1. Редактируйте файлы в соответствующих папках `src/js/` и `src/styles/`
2. Изменения автоматически применяются в браузере
3. Используйте `import/export` для JavaScript модулей
4. Используйте `@use` для SCSS модулей

## Сборка

После запуска `npm run build` готовые файлы будут в папке `dist/`:
- `index.html` - Главный HTML файл
- `assets/` - Скомпилированные CSS и JS файлы
